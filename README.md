# SH | Darba laiks

Sētnieki un uzkopēji atzīmējas **tikai ar SMS** uz biroja telefonu: `SAKU <objekta kods>` (piem. `SAKU 104`), beidzot `BEIDZU`, statuss `?`.
Adminam — objekti pa adresēm: pie katra uzkopējs un sētnieks (darbā / beidza / nav), tabele ar Excel, SMS žurnāls un sūtīšana, objektu kodi un darbinieki.

Atveras tikai portālā: https://vaitkevix.cloud/sh/#dl · API: Worker `/dl`, SMS webhook `/dl/sms` (repo portals, `worker/src/darbalaiks.js`, D1 `dl_*`).
SMS vārteja: Android telefons ar «SMS Gateway for Android» (https://sms-gate.app, Cloud režīms).
